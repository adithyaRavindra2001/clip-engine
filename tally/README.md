# Tally of published clips

`uploads.csv` gets one line per clip the moment it is uploaded and submitted (by `clip upload`, or by you via
`clip posted <name> <url>`): date, pack name, campaign, title, YouTube URL, when it was posted, when it was
submitted on Content Rewards, and whether it was automatic or manual.

    clip tally          print it with per-campaign counts

Views and earnings live in the review page / database (`clip stats`), keyed by the same YouTube URL.
