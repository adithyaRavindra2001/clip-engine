Clip Engine

A personal tool that turns long-form podcasts and streams into short vertical clips, reviewed by hand before publishing.

What it does

  1. Finds new long-form videos from creators who have given permission to be clipped, using the YouTube Data API.
  2. Transcribes them locally and selects the strongest moments.
  3. Renders 9:16 clips with captions and an on-screen hook.
  4. Queues every clip for manual review. Nothing is published without a person approving it.
  5. Uploads approved clips to the operator's own YouTube channel, using the YouTube Data API.

How it uses the YouTube API

  • Read: channel upload lists and video metadata for creators on the operator's permission list, to find new episodes.
  • Write: uploading short clips to the operator's own channel, with the operator's own OAuth consent.
  • It stores only video IDs, titles, durations and view counts needed to decide what to clip. It does not collect data about viewers or other users, and it does not sell, share or display YouTube data to anyone.
  • It is run by one person for one channel. It is not a hosted service and has no third-party users.

Permission first

The engine only processes creators marked as allowed in its configuration, meaning the operator has joined that creator's clipping programme or has written permission. Every clip credits the source.
