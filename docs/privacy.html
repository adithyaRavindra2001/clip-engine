Privacy Policy

Clip Engine · Last updated 26 October 2026

Clip Engine is a single-operator tool. It runs on the operator's own computer and is not offered as a service to the public.

Data it accesses

Through the YouTube Data API, Clip Engine reads public video metadata (video IDs, titles, durations, publish dates and view counts) for channels on the operator's permission list, and uploads videos to the operator's own channel after the operator grants OAuth consent.

Data it stores

Video metadata and the operator's own clip decisions are stored in a local database on the operator's computer. No personal data about viewers, subscribers or any third party is collected. No data is sold, shared or transferred to anyone.

Google user data

Clip Engine's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Authorization tokens are stored locally and can be revoked at any time at myaccount.google.com/permissions.

YouTube

Clip Engine uses YouTube API Services. By using it, the operator agrees to the YouTube Terms of Service and the Google Privacy Policy. Stored YouTube data is refreshed or deleted within 30 days.
